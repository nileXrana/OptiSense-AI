16. API ENDPOINTS
================================================================================

Core APIs:
- POST /api/chat - AI conversations
- POST /api/save-user - User registration
- POST /api/selected-assistants - Save selections
- POST /api/user-instruct - Create custom assistant
- POST /api/delete-assistant - Remove assistant
- POST /api/updateToken - Track credit usage

Payment APIs:
- POST /api/razorpay/create-order - Payment initiation
- POST /api/razorpay/verify-payment - Signature verification
- POST /api/razorpay/webhook - Payment notifications

Feedback APIs:
- POST /api/feedback - Submit feedback
- POST /api/get-feedback - Fetch testimonials
